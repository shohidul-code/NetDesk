# কখন দেবেন

প্রতি মাসের বিল পরের মাসের ১০ তারিখের মধ্যে পরিশোধ করুন।

# bKash দিয়ে

1. bKash অ্যাপে Send Money অথবা Make Payment বেছে নিন।
2. অফিসের মার্চেন্ট নম্বর দিন (অ্যাপের হোম পেজে লেখা আছে)।
3. বিলের সঠিক টাকা লিখুন।
4. Reference ঘরে আপনার কাস্টমার কোড লিখুন, যেমন ND-000123।
5. পিন দিয়ে নিশ্চিত করুন এবং TrxID (লেনদেন নম্বর) লিখে রাখুন।

# Nagad দিয়ে

ধাপগুলো একই। Nagad অ্যাপে Merchant Pay বেছে নিন, কাস্টমার কোড Reference-এ লিখুন, TrxID রেখে দিন।

# পরিশোধের পরে

TrxID অফিসে জানান। অফিস যাচাই করলে বিল "paid" দেখাবে। সাধারণত এক কর্মদিবসের মধ্যে যাচাই হয়।
