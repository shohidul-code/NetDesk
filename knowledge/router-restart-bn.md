# কখন রিস্টার্ট করবেন

ইন্টারনেট বন্ধ হয়ে গেলে এবং অ্যাপে আপনার এলাকার কোনো নোটিশ না থাকলে আগে রাউটার রিস্টার্ট করুন। ছোটখাটো সমস্যা এতেই ঠিক হয়ে যায়।

# ধাপগুলো

1. রাউটারের পাওয়ার ক্যাবল খুলে ফেলুন। ONU (ফাইবারের ছোট বাক্স) চালু রাখুন।
2. ৩০ সেকেন্ড অপেক্ষা করুন।
3. পাওয়ার ক্যাবল আবার লাগান।
4. লাইটগুলো স্থির হতে ২ মিনিট অপেক্ষা করুন, তারপর কোনো ওয়েবসাইট খুলে দেখুন।

# তবুও কাজ না করলে

ONU-এর লাইট দেখুন। LOS লাইট লাল হলে ফাইবারে সমস্যা: নিজে তার টানবেন না, অ্যাপে অভিযোগ করুন। অন্য ক্ষেত্রে "no internet" বিভাগে অভিযোগ করুন।
