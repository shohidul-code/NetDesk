# ধাপগুলো

1. রাউটারের সাথে যুক্ত ফোন বা কম্পিউটারে ব্রাউজার খুলুন।
2. রাউটারের নিচের স্টিকারে লেখা ঠিকানায় যান (সাধারণত 192.168.0.1 বা 192.168.1.1)।
3. স্টিকারে লেখা ইউজারনেম ও পাসওয়ার্ড দিয়ে লগইন করুন।
4. Wireless বা Wi-Fi মেনুতে যান।
5. Password বা Pre-shared Key ঘরে নতুন পাসওয়ার্ড লিখুন। কমপক্ষে ১০ অক্ষর দিন।
6. Save চাপুন। সব ডিভাইস নতুন পাসওয়ার্ড দিয়ে আবার যুক্ত করুন।

# লগইন করতে না পারলে

স্টিকারের পাসওয়ার্ড কাজ না করলে অফিসে যোগাযোগ করুন। টেকনিশিয়ান রাউটার রিসেট করে দেবেন। নিজে রিসেট বোতাম চাপলে রাউটারের সব সেটিং মুছে যেতে পারে।
